### Strengths During the Internship

- **Applying AWS Knowledge to the Project:** Understand how Python on EC2 processes data, Amazon S3 stores Parquet files, and AWS Glue Data Catalog provides table metadata for queries using Amazon Athena.
- **Understanding How System Components Work Together:** Understand that account data and personal activity information are stored in S3, while moderation information and audit logs are stored in DynamoDB. Recognize the role of the Projection Worker in data synchronization.
- **Verifying Information Before Reporting:** Review source code, configurations, commands, and test results to determine the verification status of each function deployed on AWS.
- **Organizing Documentation Step by Step:** Structure worklogs, proposals, and workshop materials so readers can follow each stage and compare the results.

### Areas for Improvement

- **Strengthening Technical Knowledge:** Practice optimizing Athena queries, configuring appropriate IAM permissions, and evaluating operational costs based on actual usage data.
- **Improving Troubleshooting and Recovery Skills:** Develop skills in analyzing logs, handling data pipeline interruptions, checking backups, and practicing recovery scenarios involving EC2 restarts.
- **Writing Clearer and More Concise Technical Documentation:** Use diagrams, actual screenshots, test dates, or execution IDs to help readers verify and reproduce results.
- **Enhancing Testing Skills:** Practice designing integration test scenarios, measuring system performance, and clearly documenting whether tests were performed locally or on AWS.
- **Tracking Progress More Consistently:** Divide tasks into smaller steps and update worklogs regularly to identify difficulties and unresolved issues earlier.

After completing the internship, I plan to continue studying **Python, Data Engineering, and Cloud Computing**, while strengthening my skills in data processing, SQL querying, security, and system operations on AWS.
